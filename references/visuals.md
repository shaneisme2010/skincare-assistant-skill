# 真实资产与视觉交付

## 可交付的前提
首次完整流程需要两份视觉：照片评估后的Skin Report、产品匹配后的Skincare Plan。后续上传照片生成[复评对比报告](reassessment.md)，仅在方案实际变化时更新相应方案图。生成一个图片文件只证明工具返回了产物；须核验内容和资产来源，才能称为合格交付。

当前聊天中，优先用实际可用的非生成式裁切/排版工具（例如支持直接引用原图的HTML/SVG、画布、图像合成能力）组合资产。先确认能访问源图和工具能力，再执行。不默认转交Work或创建另一聊天；失败按[恢复与反馈](recovery.md)。仅有整图生成能力时，可以制作明确标注的布局示意或不含伪造照片/包装的图形，但不能用它代替真实资产报告。

图像生成可用于独立装饰背景、图标或通用线稿，不用于重画皮肤、补纹理、超分辨补证据、改变瑕疵或重新生成产品瓶身。给生成工具传了参考图，不证明产物保留了原始像素。没有原资产引用与制作记录时，真实性状态是“未核验”，不武断说一定伪造，也不判通过。

## 资产记录与制作
内部保留轻量资产表（可在当前工具数据中，无需用户填表）：
- 皮肤局部：输入照片的可访问引用、裁切矩形/区域、对应问题编号；只做裁切、必要缩放和独立标注覆盖，不用颜色调整伪造临床细节。
- 产品图：准确产品编号/版本、来源页面、实际可访问的图片引用、身份核验结果。
- 输出：采用的排版工具、生成文件/画布引用、资产对应关系、验收状态及缺项。

用图片工具实际读取/检查资产，按环境授权引用或获取，不绕过访问限制。画完后打开实际成品检查图文与源资产对应、是否可读；无法打开验收就写“视觉验收未完成”。资产表是可追溯制作记录，不冒充像素级取证。用户不需看到内部资产路径或过程说明。

## Skin Report 图内模板
纵向报告，留白与圆角卡片，依次显示：
1. 标题、基线日期、简短肤况概括。
2. 必要自述摘要：油干/耐受、目标与过敏信息；仅在私有报告需要时呈现，不进入公共示例。
3. 局部真实细节图：额头、鼻、面颊等按实际问题选择。无完整正脸、45°整脸、整脸缩略图；不以多块局部拼回人脸，尽量裁掉眼睛/背景等识别特征。局部图仍不等于完全匿名。
4. 每个有视觉依据的问题都有对应局部图和编号标注：问题名、位置、观察依据、可能解释、置信度及原因。按证据支持程度显示，不能为版面捏造问题。
5. 简短局限与需要用户确认的内容；页脚“视觉评估不等于医学确诊”。

色圈/细框对应实际问题，不能随意圈满区域或遮住关键细节：橙色黑头/皮脂丝，蓝色毛孔，紫色油光，红色泛红/红点；同时标问题编号、文字与图例，不只靠颜色。细节不足如实注明，不能补造。
直接写可理解的问题名，例如“疑似黑头，可能混有皮脂丝”；区分照片观察、自述和病因解释。程度有依据才写；置信度用高/中/低加原因，不编百分数。反光不是皮脂实测，红点不是疾病确诊。问题分流见[医学边界](safety.md)。

## Skincare Plan 图内模板
沿用报告视觉系统，以清晰的产品分栏呈现：
1. 标题、当前方案版本与生效状态、周期目标；AM、PM或实际需要的PM-A/PM-B/PM-C栏目。所有仍有效目标在图中能找到对应处理或暂缓说明。
2. 五个默认产品位置，依[产品方案](products.md)排列。每项有步骤编号、完整具体产品名、真实产品图、简短适配理由、用量、部位、频次、必要注意事项。长产品名不得截断为泛称。
3. 非每日产品的周日历；字母与栏目及分阶段频率一致，不能遗漏实际已采用的C晚。
4. 通用线稿的重点护理区域、使用要点、避免叠加、刺激时Plan B、4/8/12周复评提示。

参考图只借用布局，不继承其中品牌、成分、规格、频率或疗效。产品角色明确标“爽肤水”“功能精华”等；同款跨栏目复用可用编号关联完整产品卡，不能省到只剩“同上”且找不到用法。需暂停的步骤在图内说明。

## 视觉标准与验收
背景#F7F7F4，正文深蓝#23354D，白色卡片，AM淡暖色、PM-A淡紫、PM-B淡绿。纵向手机可读，层级清晰、留白适当；放不下拆连续页，不能把必要内容挤到图外。装饰不得抢占产品和细节图空间。
交付前逐项核对：无完整人脸；真实局部图、标注与问题一致；皮肤与产品资产都有来源；每个已选产品在图中完整出现、图名对应；用法/注意事项/周历齐全；无乱码、截断或过小文字。失败则仅修复相应页面。
缺少真实图时保留准确名称并标“图片待核验”；不能造图填位或把部分交付说成完成。完全无可行视觉工具时说明限制，提供结构化临时结果与反馈入口，保留未完成状态。商品轮播、纯正文或未渲染代码均不是已交付方案图。
正式方案图展示后继续[提醒与随访处理](continuity.md)，不以“图已生成”或“需要的话可以设置提醒”作为流程终点。仅重排版/修图而未改护理内容，沿用已处理状态。
