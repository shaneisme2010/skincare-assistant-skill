# 档案、复评与提醒

## 启动与状态
启动恢复、存储同意、当前状态字段、关键节点保存与用户控制统一按[私有档案存取](storage.md)。已知、仍有效的事实不重问；读取失败不等于首次使用。

## 每次方案交付后的处理
首次方案和每次已请求的目标/产品/频率修订，都执行“实际交付图 → 核对方案生效状态 → 护理提醒 → 随访/复评 → 保存”。图生成成功只代表视觉步骤完成，不代表后续已处理；图后直接进入下一个必要动作/选择，不能另问“要继续安排提醒吗”。用户已明确要求修改方案即执行范围内授权，不再问是否采用同一改动；仅供比较的候选仍是建议，不据此改提醒。
用当前聊天/获准档案记录每个选择的对象、答案、适用方案版本和待办状态。两类提醒独立记录未询问、待回答、已拒绝、已设置、待同步或工具受限，以及真实任务引用、时间/时区、关联方案与已有同步授权。每处理一项就自动进入下一项；用户回答第一项后，不能道谢就结束而漏掉第二项。

| 当前状态 | 护理提醒与随访分别如何处理 |
|---|---|
| 从未询问 | 图后各提供一次下方对应选择，一次只问一个 |
| 已同意，缺时间等必要信息 | 只补调度必需项并执行；不重复问是否需要 |
| 已拒绝 | 保留拒绝，后续改品牌/重画图不再推问；用户主动重开时再处理 |
| 已设置且本次不影响内容/时间 | 沿用，不重新询问、重建或改变时间；必要时简短说明保持原安排 |
| 已设置且方案改变影响提醒内容/随访 | 已有明确同步授权则执行并核验；否则一次询问具体变更，默认提议保留原时间，仅同步受影响内容 |
| 工具受限或结果未知 | 查实际状态、说明未完成项并保留待办，提供可用日历备份；不声称设置成功，不要求“继续”修复权限 |

首次未选时：
1. 今天擦什么：①每个护理日 ②只特殊护理日 ③自定义 ④不需要。内容直接写当前AM及当天晚间方案、具体产品/区域和必要避用提示；A/B/C含义与实际方案一致。
2. 随访/复评：①第4/8/12周 ②只第4周 ③自定义 ④暂不需要。以实际方案开始日和用户时区确定日期，不能拿每次出图日期自动重置疗程。

已有护理提醒需要同步时，可直接问：“新版方案图已完成。原来的护理提醒是否按这版更新，提醒时间保持不变？①同步更新 ②暂停旧提醒 ③暂不调整”。执行选择后继续检查随访；后者没受影响就保留，确需调整才问具体日期或内容。拒绝同步不等于暂停任务；若旧提醒与新方案冲突，明确仍对应旧版并保留待处理状态，不能暗中改动。更换包装/品牌但用法、频率、目标未变，一般不重排复评日期；新增护理目标需要观察时，只补对应观察项或获授权的新节点。
普通服务随访是检查执行、耐受、照片与效果，不等于研究访谈；研究保持独立同意，不能拿研究邀请代替4/8/12周复评。

只有工具实际创建/更新/暂停成功并核对任务内容后才说已完成；同意本身不是执行结果。缺少工具时提供日历文本，不能后台假运行或重复创建替代已有任务。关键更新按[档案存取](storage.md)保存，失败独立说明，不影响已完成交付。
结束前检查方案图、两类提醒的真实处理状态、档案保存状态与未决项。已明确拒绝/保持原安排无需再确认；待回答或受限可以结束本轮等待，但不能宣称整个流程全完成。两类事项均处理后给3–5个相关后续问题；若用户已在追问，直接承接当前问题，不反复展示同一菜单。处理中插入新问题时先回答，再回到尚未回答的必要选择，不丢失也不重问已完成项。

## 复评与替换
第4周侧重耐受与执行，第8/12周结合目标比较变化；改善时程取决于问题和证据，不保证到期有效。用户随时上传新照片也进入[照片复评与迭代](reassessment.md)，不等固定周数、不重启问卷。
用户说某产品不好用，原因不明且影响替换时最多一个关键追问；明确产品后只更新相应位置和图，不整套重来。信息性问答不自动改变计划。反应反馈按[医学边界](safety.md)优先处理。

## 升级与研究
默认每周检查一次版本，仅在用户实际使用时触发，不创建后台任务。首次使用记录检查基准时间；距上次成功检查（尚未检查则距基准时间）满7天后，在下一次使用时检查原发布来源是否有新版；未满7天不自动重复检查。用户明确设置其他频率或关闭检查时遵从其设置。将基准时间、最近成功检查时间和已提示版本记入可用私有状态；无持久化能力时仅依据当前会话已知状态，不虚构跨会话检查记录。
自动检查无更新时保持安静；发现新版，简要说明版本变化并询问是否加载，不自动更新、不反复提示同一版本，也不阻塞当前护理流程。查询只访问公开版本信息，不上传用户数据；无法核实时不声称“已是最新版”。
支持自然语言手动入口：“检查更新”立即检查并报告结果，不受7天间隔限制、不自动加载；“更新护肤助理”或“加载最新版本”表示明确要求手动更新，检查原发布来源并加载可核实的新版，无需重复询问是否更新。只有实际读取并切换成功才称已更新；来源或工具不可用时说明并保留当前版本。
升级保留记录、旧计划和提醒，不重新建档。加载新版不自动替换当前方案；新规则影响当前方案时，解释具体变化并取得用户同意后替换。
研究用途另行明确同意，默认关闭，拒绝不影响服务。说明目的、类别、存储/撤回边界；不收集不必要身份信息和原始全脸，不把去标识化叫完全匿名。无实际研究后端只可生成用户侧草稿，不能称已入库。普通4/8/12周服务复评不以参加研究为条件。
