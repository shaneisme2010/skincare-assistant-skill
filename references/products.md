# 产品匹配与问题对应方案

## 追问与修订的表达
先判断本轮是在解释问题、要求修改现有方案，还是明确只要成分建议。普通成分问答直接回答，不重启问卷/出图/提醒设置；用户要求调整目标、品牌或产品时，沿用已有资料和已授权的方案交付流程。只有真正缺少会影响安全/选择的信息才追问，不能问“是否开始筛选”“是否继续生成图”。
追问中的方案说明默认简短：已确认目标 → 拟用成分/作用机制 → 安排在哪一步/时段 → 必要注意事项或局限。图前文字不铺商品候选、价格、购买链接或购物轮播；证据引用与购买入口分开，仍可提供必要文献依据。产品身份、配方、地区可获得性和图片来源照常内部核验，真实产品名/图与完整用法进入最终方案图。用户明确要具体产品名单时简要给名称和理由，只有询问来源/购买入口时提供相应产品链接。
用户只要成分简案时遵从，不强行商品化或出图；这不取消其他用户已经请求的正式方案图。用户已要求“按这个改/生成图/继续”时，简要解释后同轮执行到实际交付，不以“我可以重做”结束，也不额外要求批准同一简案。
修订先核对所有仍有效目标及取舍；新增提亮、皱纹或品牌偏好不自动删除原有黑头/出油等目标。每个目标对应处理位置或明确暂缓理由，不能以“抗老”泛称掩盖遗漏的皱纹目标。不把品牌营销定位当临床证据，不为满足品牌偏好无依据增加活性。

## 匹配顺序
确认的目标 → 适用证据支持的干预 → 过敏/耐受与重复成分 → 准确候选及官方配方 → 地区可获得性 → 真实产品图片 → 方案。
证据检索用[常见肤况手册](concerns.md)。不能先找商品再编适配理由，也不能将成分研究等同于该成品已经证实有效。

到产品匹配时应用开场记录：避开已知过敏原和明确诱因，并核对具体版本的完整配方；曾发生反应的产品单独标记并避免再次推荐，不把其中所有成分一概判为过敏原。反应原因未知就保留未知，不声称已排除过敏；仅在候选安全取舍确实依赖缺失信息时做最小澄清或换可核验候选，不倒退重跑过敏问卷。

品牌为软偏好；只提供品牌时优先同品牌或相近档次品牌，不推断具体库存。用户严格限定品牌时遵守，确实无合适选项则说明；未提供产品/品牌时直接按证据全新推荐，不反复追问。匹配优先考虑安全、证据、方案兼容与用户偏好，不给未经校准的评分，不用销量、广告、佣金决定推荐。合适的原产品优先复用，只补缺口。

## 已有产品逐件评估
只要用户提供具体在用产品，正式方案就必须有“已有产品评估与用法”，逐件保留准确名称/版本与来源；品牌名称本身不是具体产品。每件标记：**继续用／调整用法／暂停使用／信息不足**，并说明与肤况、目标、耐受和重复成分相关的理由。无需新增或重复产品可列“暂停使用（当前方案不需要）”，区别于安全性不适合。
可用产品写明对应问题编号、AM/PM步骤、用量、部位、顺序、频次和注意事项；调整时写出具体变化，暂停时写原因和本轮是否需要替代。信息不足时列最小缺项，不能冒充已核验或给确定安全结论。无需用户提供全部产品或手填全部INCI才能推进；自己核验可查事实，先完成已知项和其他步骤。既有产品、新推荐和未完成项在图、文字、档案中一致。

## 问题与方案逐项对应
从已确认报告/自述建立可追溯关系：问题编号与部位 → 观察/解释置信度 → 护理目标 → 适用证据 → 具体步骤/产品编号 → 用法 → 复评指标。每个仍有效问题必须对应行动，或写出暂缓、证据不足、非护肤品可改善范围及理由；不把“抗老”“基础保湿”当成所有问题已处理。一个产品可对应多个问题，不能为每个问题强塞一件商品。修订时保留未取消目标，逐项核对无遗漏。

## 有眼周问题时的附加步骤
报告或自述支持眼周干燥、细纹等适合日常护理的问题，且当前无活动炎症/红旗时，在方案中加入清晰的**眼霜／眼周护理步骤**并关联该问题编号，不被默认五步上限挤掉。无需人人添加眼霜；如已有产品明确适用于眼周且已耐受，可以复用并标明，不强迫另买。
核验具体产品的眼周适用范围和说明后，写明单次用量（按该产品说明，不统一套“米粒大小”）、可涂部位、顺序、AM/PM与频次、避开部位及刺激时处理。默认排在精华之后、面霜之前，具体产品说明不同则明确调整；防晒仍在白天最后的护肤步骤。避开眼睛、黏膜和睫毛根部；未明确适用于活动眼睑的产品不涂该处，不能把面部酸/维A用法直接搬到眼周。缺少关键用法/适用信息则换可核验候选或标未完成，不编造剂量。
活动性红、肿、痒或破损先按[眼周问题](concerns.md)及[风险分流](safety.md)处理，在眼周位置写暂缓原因，不自动加功效眼霜。眼痛、畏光或视力改变需及时医学评估。照片只能支持外观观察，不能确诊病因；不承诺眼霜消除结构性黑眼圈、泪沟或眼袋。

## 地区与事实
确认该具体产品能通过常驻地区品牌渠道、正规零售或可信合规进口渠道获得；“品牌在当地销售”不足以证明该产品可获得。可以使用当地可获得的进口版本，无需强制找中文包装/当地独立SKU。价格、汇率、最低价、评分、促销和逐店库存不属于默认任务；外币搜索结果不是不可获得的证据。

核对完整产品名、剂型、浓度、当前配方和必要的市场版本；只有版本差异影响身份/适配时进一步核验。优先官方完整INCI；无法取得时保留未知项，不能声称已完整核验或据此排除过敏原。事实关键缺口无法解决则换可核验候选，不围绕同一产品无限搜索。仍无法匹配时明确该位置未完成及原因。

每个最终产品对应一个内部记录：产品编号、准确名称/版本、作用位置、对应问题编号、已有/新推荐、已有产品评估结论（如适用）、官方产品/配方来源、当地可获得性来源、真实图片来源与资产引用、选择理由、用量/部位/顺序/频次、相关注意事项、核验日期和未知项。来源可共用同一页面；信息量不影响选择时不做无谓核验。普通产品问题不要求用户手填INCI，只有找不到必要事实时才请其提供。

## 默认顺序
- AM：洁面 → 爽肤水/化妆水 → 精华 → 面霜 → 防晒。
- PM：洁面 → 爽肤水/化妆水 → 精华 → 面霜。

五步是默认基础，不是步骤数量上限；符合上面眼周条件时插入眼霜／眼周护理位，图、周历、档案和提醒同步更新。

正式产品方案中每个位置都要有具体产品和用法；“水”不是清水。面霜位如选乳液/凝胶，说明适配理由。此结构是默认产品体验，不宣称每步医学上必需；确实不适合、重复或反应期需简化时，保留位置并在图内说明“暂缓/省略原因”。不能无说明省掉水或精华，也不能为填满位置增加刺激活性。

精华可按目标选温和或功能型；水杨酸精华已属于精华，不额外凑第二款。非每日功能精华用周历写明起始频率；通常A/B足够，有实际需要可用A/B/C，图、文字、档案与提醒的字母含义和日期必须一致，不为新增目标固定凑三种晚间方案。修护日可用合适温和精华或注明当晚停用功能精华。先明确剂型、耐受、实际产品说明与适用证据，再确定量与频次；不默认所有酸都每周两次、不固定每步等30–60秒。必要时按阶段调整，不能把“耐受好”当安全保证。

核心推荐应说明针对什么问题、为什么选、预期改善的范围与局限。重复成分、使用区域和不宜同晚叠加写成可执行提示；刺激时减量/暂停和转医学评估按[风险分流](safety.md)。处方、口服药和医美操作不塞入化妆品五步方案。

## 交付
正式方案的具体产品名、真实图片和完整用法必须进入[方案图](visuals.md)；图外按上面的简案规则说明，不默认商品链接。不要调用购物卡/商家轮播代替方案；无法控制的平台商业组件不作为推荐依据，不声称已移除未能控制的内容。
初次方案及每次有效修订都在图交付后执行[交付后的提醒与随访](continuity.md)，不能只在第一次运行。用户换品牌或反馈不好用时，只重算受影响产品位，解释对应目标；仅视觉重排而方案未改，不重复提醒选择。
