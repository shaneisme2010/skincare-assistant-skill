# 护肤聊天包 0.1.0-rc.6（公开测试版）

只需要一个文件：**SKILL.md**。问卷、风格说明与原非商业许可均已内联。

1. 从[本版发布页](https://github.com/shaneisme2010/skincare-assistant-skill/releases/tag/skincare-chat-starter-v0.1.0-rc.6)的 Assets 下载 **SKILL.md**。
2. 在 ChatGPT 新聊天中上传完整文件，发送：请完整读取这个 SKILL.md，按其中流程开始护肤评估。
3. 新聊天需要重新上传。文件用于当前聊天读取，不会永久安装 Skill 或创建插件。照片可选。

[直接阅读完整文件](https://github.com/shaneisme2010/skincare-assistant-skill/blob/skincare-chat-starter-v0.1.0-rc.6/chat-starter/SKILL.md) · [版本清单](https://github.com/shaneisme2010/skincare-assistant-skill/blob/skincare-chat-starter-v0.1.0-rc.6/chat-starter/manifest.json)

本次原样发布已冻结的 rc.6 测试快照。文件内“未发布候选”等措辞记录的是快照形成时的状态；当前公开发布状态以本版发布页为准。首次从旧多文件/ZIP 版本迁移，请手动取得并上传完整 SKILL.md。无需下载 GitHub 自动生成的 Source code 压缩包。

验证范围与尚未验证项目见发布页。一般护肤信息不构成医学诊断或处方；不要向公开仓库上传面部照片、健康资料或私密聊天。
