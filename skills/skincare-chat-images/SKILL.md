# 护肤报告与方案图片

交付两张各自完整的原生生成图片：皮肤报告、护肤方案；同时提供可读的完整用法和医学来源链接。资料齐且本人明确完成后，连续完成研究、完整说明、生图与校对，不再等一句“继续”。

护肤报告、方案及对应护理说明中的所有用户可见图文（含自动引用、脚注和来源卡）仅链接医学证据或非商品的一般护理指导，不含商品详情/购买页链接或二维码。商品页面仍须实际读取以核验身份、用法与可获得性，出处留在内部核验资料。版本检查与安装通知可单独附本包官方 GitHub 发行页，不放进护肤图文。

## 收集

首次读取并逐字发送[固定六组问卷及两个例子](references/intake.txt)，保留全部选项及两个完整例子；必要补问另列。分段回答先等本人明确“已完成”；否定、引用、条件句和撤回不作完成。只补影响判断的缺项，额外最多四个独立问题，子问题也计数；性别可跳过，未知保留未知。

真实评估在问卷后补充：“请提供本人清晰照片，一张够用就不凑多角度。照片仅私下分析；原片、真实裁切和可识别人脸不进入成品或生图参考，只用去身份化观察文字。资料给完后请回复‘已完成’。”实际私下看图后再评估。明确虚构验收走[合成分支](references/synthetic.md)。明显急症先按[风险分流](references/research.md)处理。

## 研究与生成

1. 资料完成后读[研究与选品](references/research.md)，实际核验相关医学来源、准确商品与包装参考。保留用户已有产品、品牌偏好和有效目标的区别，先确定适合的步骤。研究后先在聊天中发出完整说明：准确产品与用法、用量/部位/方法、频率与条件、厂家说明和方案建议的区别，以及医学完整题名、年份、可点击链接与适用局限。随后在本轮立即生图，不等用户确认。
2. 读[双图版式与校对](references/visuals.md)，查看中性风格参考，将前述完整说明按其中的逐卡格式整理为生图依据，带入已核包装文字、医学短引及年份和版式。首次双图任务分两次调用当前宿主原生图像工具：先仅生成皮肤报告并确认实际返回报告图，再单独调用一次仅生成护肤方案并确认实际返回方案图。
3. 每次生成或修改后，逐张打开完整最终图，按同一份逐卡依据和[成图检查项](references/visuals.md#生成后检查)重新核对，包括未改动区域。局部修订时，以当前图为编辑原图，明确目标文字框或产品卡的位置及完整替换内容，只修改该区域，要求其他区域保持原样；完整附文不能替错误图片兜底。
4. 结束首次双图交付前，分别核对报告图和方案图均已作为可打开的独立图片交付，并有前述完整说明；简短邀请用户纠正资料或成图问题。只有一张时继续生成、检查并交付缺失那张，不等用户催补；文字宣称“已生成”不算图片。若实际工具失败或关键资料缺失，说明缺项、卡点与可用成果，不宣称完整交付，也不自动改用程序排版。

普通追问直接回答；旅行、局部修订和提醒按[后续分支](references/followup.md)，复用仍有效资料。


## 版本检查

每次开始使用本助手或用户说“检查更新”时，读取[版本检查](references/updates.md)及[本包版本配置](skill-config.json)。使用时检查按真实上次检查时间节流；手动检查立即执行。该分支只通知，不创建独立后台任务，也不自动安装或覆盖。
